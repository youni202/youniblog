# App Builder 학습 가이드 (실습용)

GitHub Pages로 게시하면 누구나 브라우저에서 보고 실습 자료를 받을 수 있습니다.

## 게시 방법
1. GitHub에서 New repository 생성 (Public)
2. index.html, README.md, files/ 폴더를 업로드
3. Settings -> Pages -> Source: main 브랜치, /(root) -> Save
4. https://<사용자명>.github.io/<저장소명>/ 에서 공개

## 구성
- index.html : 학습 가이드 + 실습 3종
- files/유니_안전교육매뉴얼.docx : 실습 2 첨부 문서
- files/유니_정보보안정책서.docx : 실습 3 첨부 문서 (개인정보보호법·정보통신망법 반영)
