App Builder란?

코딩 없이, 대화로 만드는 가볍고 인터랙티브한 앱

🤖 한 줄 정의

App Builder는 Microsoft 365 Copilot 안의 AI 에이전트예요. 원하는 앱을 말로 설명하면 데이터 구조 + 화면(UI)을 자동으로 만들어 줍니다.

  • 💬 말(프롬프트)로 설명 → 즉시 앱 생성
  • 📊 복잡한 데이터를 인터랙티브 시각화로 변환
  • 📁 문서·스프레드시트·회의·메시지 등 M365 데이터 활용
  • 🔄 Copilot 채팅에서 즉시 수정·개선
  • ⚙️ GPT-5 기반 (핵심 엔진, 끌 수 없음)
⚠️
Frontier 프로그램 안의 실험적 기능이에요. 정식 출시 전이라 기능이 수시로 바뀔 수 있습니다.
🚀

시작하기 — 에이전트 찾기

기본으로 켜져 있지 않아요. Agent Store에서 직접 추가합니다

📍 추가 절차

  • Microsoft 365 Copilot에 로그인
  • 왼쪽 메뉴에서 Agents(에이전트) 선택
  • 스토어에서 Built by Microsoft / Agents / Productivity 카테고리로 이동
  • App Builder (Frontier) 를 찾아 추가(Add)
  • 왼쪽 Agents 아래에 App Builder가 나타나면 완료! 🎉

✅ 사전 조건 체크리스트

  • M365 Copilot 라이선스 — 필수
  • Frontier 프로그램 참여 — 사용 자격
  • 조직 스토어 허용 설정 — 관리자 정책에 따라 설치 가능
💡
App Builder가 안 보이면 위 사전 조건부터 확인하세요. 사용량 많은 시간엔 일시 지연(throttling)이 있을 수 있어요.
🛠️

앱 만드는 4단계

설명하고 → 생성되고 → 다듬고 → 공유하기

1

🗣️ 목적 설명하기

App Builder를 열고 만들고 싶은 앱을 텍스트로 설명해요.

예: "데모 신청자 목록을 관리하는 앱 만들어줘"
2

⚡ 앱 자동 생성

데이터를 담을 스키마(테이블)와 입력·조회용 화면(UI)이 자동으로 만들어집니다.

3

🎨 대화로 다듬기

"참가자 정보를 카드로 보여줘"처럼 기능을 계속 추가·수정. 변경은 즉시 반영돼요.

4

🔗 실행 & 공유

Play로 테스트, Share 버튼으로 링크 생성. 조직 내 Copilot 사용자에게 링크로 공유합니다.

⚠️ 파일 다운로드 ❌ · 링크 실행형 ⭕
🗑️
삭제 주의: 앱을 삭제하면 공유받은 모든 사람이 즉시 접근 불가, 되돌릴 수 없습니다.

실습 — 직접 만들어 보기

아래 3가지 프롬프트를 App Builder에 그대로 입력해 보세요

실습 ① — GitHub Copilot 학습 가이드 (간결)

코딩 없이, 한 줄 설명으로 GitHub Copilot 학습 앱을 만들어 봅니다.

프롬프트 — 복사해서 입력
GitHub Copilot을 처음 시작하는 사람을 위한 학습 가이드 앱을 만들어줘.
단계별 사용 방법과 퀴즈를 넣고, 진행에 따라 진도율이 보이게 하고,
초급·중급·고급 단계로 나눠서 만들어줘.

실습 ② — 파일 첨부: 안전교육 매뉴얼

아래 문서를 App Builder에 첨부한 뒤 프롬프트를 입력하세요.

📄 유니_안전교육매뉴얼.docx 다운로드

프롬프트 — 복사해서 입력
첨부한 '유니_안전교육매뉴얼'(또는 '유니_HR_FAQ') 문서를 바탕으로
객관식 퀴즈 앱을 만들어줘.
- 문서 핵심에서 문제 10개(보기 4개) + 정답 한 줄 해설
- 매번 10개 랜덤 출제, 다시하기 시 셔플

실습 ③ — 파일 첨부: 정보보안 정책서

개인정보보호법·정보통신망법이 반영된 정책서로 법령 퀴즈를 만들어 봅니다.

📄 유니_정보보안정책서.docx 다운로드

프롬프트 — 복사해서 입력
첨부한 '유니_정보보안정책서' 문서를 바탕으로 객관식 퀴즈 앱을 만들어줘.
- 개인정보보호법·정보통신망법 핵심에서 문제 10개(보기 4개)
- 정답 시 근거 조항을 한 줄 해설로 표시
- 매번 10개 랜덤 출제, 다시하기 시 셔플
📝

참조 예시 — 더 많은 앱 아이디어

복사해서 바로 입력하는 완성형 프롬프트 6종

① 객관식 퀴즈 앱 시험형

📋 복사해서 사용
안전교육 객관식 퀴즈 앱을 만들어줘.
- 문제 10개, 각 문제는 보기 4개
- 보기를 선택하면 정답/오답을 즉시 표시
- 마지막에 총점과 정답률(%)을 보여줘
- 다시 풀기 버튼도 추가해줘

② 학습 진도 트래커 진척관리

📋 복사해서 사용
신입사원 온보딩 학습 트래커 앱을 만들어줘.
- 학습 모듈을 목록으로 표시
- 각 모듈에 완료 체크박스
- 전체 진행률을 막대 그래프로 표시
- 완료한 모듈은 색상으로 구분

③ 용어 플래시카드 앱 암기

📋 복사해서 사용
용어 학습용 플래시카드 앱을 만들어줘.
- 카드 앞면엔 용어, 클릭하면 뒷면에 설명
- 다음 카드로 넘기는 버튼
- 이미 학습한 카드는 체크 표시
- 남은 카드 개수를 화면에 표시

④ O·X 퀴즈 앱 빠른판단

📋 복사해서 사용
제품 지식 O·X 퀴즈 앱을 만들어줘.
- 문장을 하나씩 보여주고 O 또는 X로 답하기
- 선택하면 정답 여부와 한 줄 해설 표시
- 진행 상황(예: 3/10)을 상단에 표시
- 마지막에 맞힌 개수와 점수 요약

⑤ 교육 만족도 설문 앱 피드백

📋 복사해서 사용
교육 만족도 설문 앱을 만들어줘.
- 5점 척도 평가 문항 5개
- 자유 의견 입력란 1개
- 제출 버튼과 제출 완료 메시지
- 수집된 응답을 목록으로 확인

⑥ 온보딩 체크리스트 앱 단계관리

📋 복사해서 사용
신입사원 온보딩 체크리스트 앱을 만들어줘.
- 1주차/2주차/3주차로 단계 구분
- 각 단계별 항목을 체크박스로 관리
- 단계별 완료율과 전체 완료율 표시
- 모두 완료하면 축하 메시지
🚀

고도화 — 단계별 레벨업

한 번에 다 만들지 말고, 단계별로 쌓아 올리는 게 핵심!

🔑
레이어드 프롬프팅: App Builder는 코드를 직접 못 고치고 대화로만 다듬어요. 그래서 복잡한 앱일수록 단계를 나눠 쌓아야 결과가 안 엉킵니다.
1

📐 기본 뼈대 (MVP)

데이터 구조 + 기본 화면만. "문제가 뜨고, 답 고르고, 점수 나온다"가 작동하는지 먼저 확인.

2

🖱️ 인터랙션 추가

정답=초록, 오답=빨강, 체크 아이콘, 진행 바(3/10), 답 고르기 전 '다음' 비활성화 → 살아있는 느낌.

3

✨ 감각 효과 (소리)

정답 시 짧은 성공음, 반짝임 애니메이션, 점수 카운트업. 소리는 꼭 ON/OFF 토글로!

4

🔀 고급 로직 (셔플)

다시하기 시 문제·보기 순서 무작위 셔플, 큰 문제 풀에서 매번 N개 랜덤 출제 → 항상 새로운 느낌.

5

🏆 동기부여

연속 정답 콤보, 최고 점수 기억, 정답률별 배지, 틀린 문제만 다시 풀기.

🔊 소리, 정말 집중에 도움될까?

솔직하게 말씀드리면 — "짧은 이벤트성 효과음"은 👍, "지속 배경음"은 👎인 경우가 많아요.

  • ✅ 정답/오답 효과음 → 즉각 피드백으로 몰입·재미 상승
  • ⚠️ 계속 깔리는 배경음 → 오히려 집중 방해 (학습용 비추천)
  • 🎚️ 무엇이든 ON/OFF 토글로 학습자에게 통제권을!
ℹ️
App Builder의 소리 지원 여부는 공식 문서에 명시돼 있지 않아요. 프롬프트로 요청해 보고, 안 되면 시각 효과로 대체하는 걸 권합니다.

🔀 셔플 다시하기 프롬프트

📋 복사해서 사용
다시하기 기능을 고도화해줘.
- '다시하기'를 누르면 문제 순서를 무작위로 섞기
- 각 문제의 보기 순서도 매번 무작위로 섞기
- 더 큰 문제 풀에서 매번 N개만 랜덤 출제
- 다시 풀 때마다 점수는 0부터 새로 시작
⚠️
중요: App Builder는 생성 후 List에 데이터(문제) 추가가 안 됩니다. "큰 풀에서 랜덤 출제"를 원하면 처음 만들 때 문제를 넉넉히(예: 30개) 넣어두세요. 나중에 못 늘립니다!

회사 데이터 연결하기

회사 자산(데이터)에 연결 — 단, 두 가지 도구를 구분하세요

1️⃣ App Builder로 연결 — 됩니다 (성격 주의)

앱을 만들 때 회사의 M365 데이터를 참조할 수 있어요.

  • 📄 문서·스프레드시트·회의·메시지 등 M365 소스 데이터로 앱 생성
  • 🔐 기존 권한·민감도 레이블 그대로 준수 (볼 수 있는 사람만 봄)
  • 🏢 데이터는 조직 경계 안에서 안전하게 처리
⚠️
외부(비-M365) 시스템 연결 ❌ · 생성 후 List 데이터 추가 ❌ → "내 데이터로 앱을 만든다"에 가깝고, 실시간 동기화 대시보드는 보장되지 않아요.

2️⃣ "연결해서 내용 확인·질문"이 핵심이면 → Agent Builder

회사 지식에 연결해 놓고 질문하면 찾아 보여주는 게 목적이라면 Agent Builder(선언적 에이전트)가 정통 경로예요.

연결 가능한 회사 자산한도
📁 SharePoint 사이트·폴더·파일최대 100개 파일
☁️ OneDrive 파일최대 50개
💬 Teams 채팅최대 5개 URL
🌐 공개 웹사이트최대 4개 URL
🔌 Copilot 커넥터Salesforce·ServiceNow·Confluence·GitHub 등 (관리자 허용 시)
🔐
연결 후 자연어로 질문하면 근거(출처)와 함께 답변. 기존 권한·민감도 레이블을 자동 준수합니다. ("제한된 SharePoint 검색"이 켜져 있으면 SharePoint 연결 불가)
목적적합한 도구
회사 데이터를 활용한 인터랙티브 앱·퀴즈 제작App Builder
회사 문서·지식에 연결해 질문·내용 확인Agent Builder
외부 시스템(Salesforce 등) 데이터까지 검색Copilot 커넥터 + Agent Builder
🏢

참조 예시 — 회사 자료 기반 프롬프트

사내 문서·매뉴얼을 바탕으로 만드는 실전 App Builder 프롬프트

💡
핵심 팁: App Builder는 첨부·연결된 M365 문서를 생성 시점에 참조해요. 그래서 프롬프트에 "이 문서를 바탕으로"를 명시하고, 문제는 처음에 넉넉히 만들게 하세요.

🅰️ 사내 보안정책 문서 기반 퀴즈

📋 복사해서 사용
첨부한 '정보보안 정책' 문서 내용을 바탕으로
객관식 퀴즈 앱을 만들어줘.
- 문서의 핵심 규정에서 문제 20개 자동 생성, 보기 4개씩
- 정답 선택 시 해당 정책 조항을 근거로 한 줄 해설 표시
- 매번 그중 10개만 랜덤 출제, 다시하기 시 셔플
- 마지막에 점수와 많이 틀린 주제(약한 영역) 안내

🅱️ 제품 매뉴얼 기반 학습 트래커

📋 복사해서 사용
첨부한 '제품 사용 매뉴얼'을 바탕으로
학습 트래커 앱을 만들어줘.
- 매뉴얼의 챕터를 학습 모듈로 자동 구성
- 각 모듈에 핵심 요약 + 완료 체크박스
- 모듈마다 이해도 확인용 미니 퀴즈 2문항
- 전체 진행률과 모듈별 완료율을 막대 그래프로

🅲 회의록·교육자료 기반 복습 퀴즈

📋 복사해서 사용
첨부한 교육 자료와 회의록을 바탕으로
복습용 퀴즈 앱을 만들어줘.
- 핵심 결정사항과 개념에서 O·X 문제 15개 생성
- 답하면 자료 속 근거 문장을 인용해 해설
- 진행 상황(예: 5/15)을 상단에 표시
- 다시하기 시 문제 순서 셔플, 점수 0부터

🅳 온보딩 핸드북 기반 단계별 학습

📋 복사해서 사용
첨부한 '신입사원 온보딩 핸드북'을 바탕으로
단계별 학습 앱을 만들어줘.
- 핸드북 내용을 1·2·3주차 단계로 구성
- 각 단계에 학습 카드 + 완료 체크
- 단계 끝마다 통과 퀴즈(3문항, 80% 이상 통과)
- 모든 단계 완료 시 수료 배지 표시
🔐
보안 안심: App Builder는 문서의 기존 접근 권한·민감도 레이블을 그대로 지켜요. 볼 수 없는 자료가 앱을 통해 새어나가지 않습니다.

이럴 땐 App Builder ✅이럴 땐 정식 개발·외주 🛠️

사내용 경량 도구 (신청·체크·트래커)외부 시스템·API 연동 필요

며칠이 아닌 몇 분 안에코드 소유·이식·장기 유지보수

  • 데이터 시각화 — 설문·피드백을 인터랙티브 대시보드로

Q. ChatGPT·Claude·Gemini로도 되지 않나요?

네, 됩니다. 2026년 현재 셋 다 코딩 없이 인터랙티브 앱을 만드는 기능이 있어요.

  • Claude → Artifacts: 앱·게임·퀴즈 생성, 공개 URL 공유(계정 없어도 열람), 코드 다운로드, 데이터 영구 저장
  • ChatGPT → Canvas: 글·코드 나란히 편집, 앱 미리보기
  • Gemini → Canvas: 코드·앱 생성 및 미리보기
🎯
차이는 "못하고 잘하고"가 아니라 "어디서, 어떤 데이터로, 어떻게 공유·관리되느냐"에 있어요.
